### Featured Research

| Project | What it does |
|---|---|
| [**FallenAngelRiskPremia**](https://github.com/diegodalvarez/FallenAngelRiskPremia) | Long/short fallen angel credit premia: fair-value model, mean-reversion signals, factor analysis, plus a full technical write-up. Featured by [Robot Wealth](https://robotwealth.com/the-hidden-gems-of-high-yield-bonds-fallen-angels/). |
| [**SwaptionVolPCASurface**](https://github.com/diegodalvarez/SwaptionVolPCASurface) | Streamlit app running on a Bloomberg Terminal that flags rich/cheap ATM swaption vols using PCA residual z-scores across the surface. |
| [**PCAFlylet**](https://github.com/diegodalvarez/PCAFlylet) | Replication of the Risk.net Buy-Side Quant of the Year paper on PCA-invariant flylets across Treasuries, swaps, and swaptions. |
| [**Gerber**](https://github.com/diegodalvarez/Gerber) | Python package applying the Gerber statistic to portfolio optimization, rolling correlations, PCA, and OLS. |
| [**MarkovRegimeSwitching**](https://github.com/diegodalvarez/MarkovRegimeSwitching) | Markov regime-switching models for volatility filtering and regime detection, with write-ups on SPY/QQQ. |
| [**SkewDrawdown**](https://github.com/diegodalvarez/SkewDrawdown) | Replicates Quest Partners' *Know Your Skew*: return skew as a predictor of hedge fund drawdowns. |
